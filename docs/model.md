# model.py 구현 계획

거래 한 건의 데이터 모양을 정의하는 모듈입니다. 파일을 읽거나 사용자 입력을 받지 않습니다.
현재 `Transaction` 클래스는 `pass`만 있으며 필드·메서드는 미구현입니다.

추후 `dataclass`를 적용하고 `id`, `type`, `date`, `amount`, `category`, `memo`, `tags`를 선언합니다.
날짜는 YYYY-MM-DD 문자열, 금액은 양수 정수, 타입은 income/expense로 사용할 예정입니다.
메모와 태그는 선택 입력이며 기본값은 빈 문자열과 거래마다 독립적인 빈 목록으로 계획합니다.
고유 id 생성과 입력 검증은 서비스 책임입니다.

현재 별도 함수 자리는 없습니다. dataclass가 생성할 초기화 메서드도 아직 없습니다.
JSON 객체와 모델 사이 변환은 저장소에서 구현할 예정입니다.
