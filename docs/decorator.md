# decorator.py 구현 계획

handle_cli_errors는 CLI 전체의 공통 오류 처리를 맡을 데코레이터 자리입니다.
현재 본문은 pass이며 try/except나 래퍼 함수, 데코레이터 적용은 없습니다.
ParamSpec과 TypeVar는 앞으로 감쌀 함수의 매개변수·반환 타입을 유지하기 위한 표준 라이브러리 타입 도구입니다.

추후 handle_cli_errors 안에 원래 함수를 실행하는 래퍼를 구현할 예정입니다.
예상되는 입력·파일 오류를 원인과 해결 힌트로 보여주고 스택트레이스를 출력하지 않도록 계획합니다.
정상 종료는 0, 오류 종료는 0이 아닌 값으로 연결하며 함수 메타데이터도 보존할 예정입니다.

적용 위치는 __main__.py가 호출하는 cli.run 한 곳으로 정합니다.
개별 명령, 서비스, 저장소에는 중복 적용하지 않습니다.
현재 빈 데코레이터를 실제 적용하면 원래 함수를 반환하지 않으므로, 구현 전까지 적용하지 않습니다.
